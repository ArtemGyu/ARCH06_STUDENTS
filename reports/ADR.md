# ADR-001. Предсказуемый каскад и границы компонентов

Статус: принято. Дата: 18.11.2026. Автор: Лобацкий Артём Сергеевич.

## Контекст

Две команды объединяют Atlas UI и обязательный виджет подрядчика. Реальные конфликты: primary получил vendor background rgb(41,57,168); danger tag получил background states и белый color из unlayered legacy; nested alert потерял собственную типографику. Доказательства: AUDIT.md и настоящие снимки Chrome DevTools.

## Альтернативы

| Вариант | Плюсы | Риски | Решение |
|---|---|---|---|
| Единый CSS-файл | Просто начать, нет сборки | Порядок правок связывает независимые команды | Отклонён: не задаёт границ и приоритета |
| БЭМ + регламент селекторов | Понятный публичный API и владение | Имена не управляют сторонним unlayered CSS | Используется вместе со слоями |
| @layer + локальные классы + токены | Предсказуемый приоритет и две темы | Нужно контролировать все точки импорта и важность | Выбран: проверяемые инварианты |
| CSS Modules | Изоляция имён на этапе сборки | Не устраняет глобальный vendor и не решает JS/семантику; требует сборки | Для этой заготовки не вводится |

## Решение и инварианты

Порядок normal: reset → legacy → tokens → base → components → states → utilities. Reset содержит box-sizing через :where(). Все импорты именуют слой; новый vendor-v2 находится во вложенном legacy.vendor-v2 и имеет префикс .legacy-widget. Из важности не строится API.

Публичные классы, DOM-слоты, размеры и состояния перечислены в CSS_API.md. В компонентах одна база ui-button; модификаторы принадлежат семействам; нет ID, глобального .is-danger, hardcoded hex в components/states и important в CSS. :where() снижает специфичность; :is() объединяет однородные классы; :has() читает состояние собственного поля. Карточка оформляет прямой h3/p/meta/button, не потомков других семейств.

Темы: html[data-theme] выбирает таблицу семантических токенов. Нормальные слои сравниваются до специфичности. Поля получают aria-invalid после blur/submit, checkbox остаётся native и dialog открывается showModal(). Container query измеряет content box карточки, а не viewport; <=400px растягивается только её прямая кнопка.

## Последствия и риски

- Автоматизация выполнена в Chromium/Chrome; Firefox, Safari, screen reader и визуальная оценка пользователем не проверены. Их следует добавить перед промышленной поставкой.
- Layers и префикс vendor работают при соблюдении точки импорта. Новый unlayered CSS или important способен нарушить контракт; CI и ревью должны блокировать такие изменения.
- Контраст рассчитан для непрозрачных computed RGB-пар и не доказывает весь WCAG. Нет автоматической пиксельной эталонной регрессии; шрифты и версия браузера влияют на снимки.

## Контрпримеры

1. Добавление important создало бы гонку и обратный порядок слоёв; исходное vendor important нужно устранить в его источнике.
2. Одного layer недостаточно для required UX, show()/showModal(), display:none checkbox, min-width и наследования цвета внутри вложенного компонента.

## Проверка следующей интеграции

Новый CSS получает границу vendor и ранний слой. Ревью исключает неслоёные импорты и утечки; npm run test:all проверяет состояния, контраст и интеграцию; новые режимы темы меняют только tokens.css.
